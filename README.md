## The word

> **Byewalk (n.): the awkward moment of saying goodbye to someone, then walking in the same direction as them.**

One new English word, defined in a single clear line of 106 characters.
It names a small daily moment everyone recognises at once and English has
no word for: the goodbye that does not end the encounter, because you both
turn and walk the same way.

## How it works

`main.py` writes that one deterministic line to `/output/entry.txt` and
validates the competition gate first: UTF-8 text of 1 to 140 characters,
not only white space, a single line. See [FLOW.md](FLOW.md).
